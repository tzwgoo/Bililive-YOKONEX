# 设备后台管理

## 功能说明

设备后台由两个部分组成：

- 本地客户端静默运行远控代理，主动连接管理服务器。
- 独立管理服务器提供登录页面、在线列表、设备状态和远程控制。

客户端不显示远控菜单、按钮或连接状态。未配置管理服务器时，远控代理不会启动。

## 启动管理服务器

复制配置模板：

```powershell
Copy-Item .env.management.example .env.management
```

编辑 `.env.management`：

```env
MANAGEMENT_HOST=0.0.0.0
MANAGEMENT_PORT=9000
MANAGEMENT_DATABASE_PATH=data/management.db
MANAGEMENT_ADMIN_USERNAME=admin
MANAGEMENT_ADMIN_PASSWORD=请设置高强度密码
MANAGEMENT_REGISTRATION_TOKEN=请设置足够长的随机注册密钥
MANAGEMENT_COOKIE_SECURE=false
MANAGEMENT_SESSION_HOURS=12
```

启动：

```powershell
python run_management.py
```

浏览器访问：

```text
http://服务器地址:9000/admin
```

`MANAGEMENT_HOST=127.0.0.1` 只允许本机访问。局域网部署需要改为 `0.0.0.0`，并在防火墙中仅开放需要访问的来源。

## 配置客户端

编辑客户端持久化目录中的 `.env`：

```env
MANAGEMENT_WS_URL=ws://服务器地址:9000/device/ws
MANAGEMENT_REGISTRATION_TOKEN=与管理服务器相同的注册密钥
MANAGEMENT_CLIENT_NAME=直播电脑
MANAGEMENT_HEARTBEAT_SECONDS=15
```

重新启动客户端后会自动注册。服务器签发的独立设备令牌保存在：

```text
config/remote_control_identity.json
```

该文件包含设备凭据，不要上传或分享。注册完成后，客户端后续连接使用独立设备令牌，不再发送注册密钥。

## 波形同步

客户端会在以下时间上报波形摘要：

- 首次连接成功。
- 断线重连成功。
- 本地波形发生变化后的下一次心跳。
- 管理服务器主动请求同步。

上报内容只有波形 ID、名称、设备类型和版本哈希，不包含具体波形步骤。管理端只能播放该客户端当前上报且与目标设备兼容的波形。

## 支持的远程操作

- `command.send`：发送 `command_one` 至 `command_ten`。
- `waveform.play`：播放客户端当前存在的波形。
- `waveform.stop`：停止指定设备正在执行的波形。
- `output.fixed`：按固定强度输出 1 到 60 秒；EMS 强度范围为 1–180，普通 Toy 为 1–20。
- `device.disconnect`：断开指定蓝牙设备。

每条命令都会校验客户端、设备、波形版本和有效期，并保存执行结果。

GCQ 设备包含气阀、气泵和水泵三个不同含义的通道，因此不提供单一固定强度控制。

## HTTP 和 HTTPS

系统不强制使用 HTTPS/WSS。局域网可以直接使用 HTTP/WS。

公网使用 HTTP/WS 时，管理员密码、Session、设备令牌和控制命令可能被监听或篡改。公网部署建议通过反向代理配置 HTTPS/WSS，并设置：

```env
MANAGEMENT_COOKIE_SECURE=true
```

客户端地址同时改为 `wss://`。
